# 🕊️ Investigación Científica y Biológica: Tórtola Inca (Columbina inca)

## 📖 Descripción
Página web educativa e interactiva sobre la **Tórtola Inca (Columbina inca)**, también conocida como tortolita mexicana. Este proyecto presenta información detallada y rigurosa sobre la taxonomía, anatomía, plumaje, distribución, comportamiento, alimentación y estado de conservación de esta fascinante especie de ave.

## 🚀 Cómo Ejecutar el Proyecto

Este proyecto puede ejecutarse de dos maneras, dependiendo de tus necesidades:

### Opción 1: Ejecución Directa (Sin servidor)
Ideal para una revisión rápida del diseño y contenido.
1. **Clona o descarga** este repositorio.
2. **Navega** a la carpeta `templates`.
3. **Abre el archivo** `investigacion_cientifica_biologica.html` directamente en tu navegador web (doble clic).
4. **Navega** por las diferentes secciones usando los botones al final de la página.

### Opción 2: Ejecución con Flask (Recomendada / Entorno de desarrollo)
Ideal para simular el entorno de producción real del proyecto.
1. Asegúrate de tener [Python](https://www.python.org/) instalado en tu sistema.
2. Abre una terminal en la carpeta raíz del proyecto.
3. Instala Flask (si no lo tienes): 
   ```bash
   pip install flask

## 📝 Contenido

### Secciones Incluidas:

1. **Taxonomía y Etimología** - Clasificación científica y origen del nombre
2. **Anatomía y Morfología** - Medidas, peso y características físicas
3. **Patrón de Plumaje** - Colores, alas y dimorfismo sexual
4. **Distribución y Comportamiento** - Hábitat y hábitos
5. **Alimentación** - Dieta y ciclo de vida
6. **Estado de Conservación** - Impacto urbano y protección

## 🎨 Diseño

- **Fondo:** Video en loop con efecto parallax
- **Contenedores:** Blanco semitransparente (75% opacidad)
- **Tipografía:** MV Boli
- **Colores:** Paleta natural inspirada en el hábitat de la especie
